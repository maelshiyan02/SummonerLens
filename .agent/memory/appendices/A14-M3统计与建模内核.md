## 1. 范围

在 M1（知识底座）/ M2（数据管道）之上，落地**统计与建模内核**：Wilson 下界排序与样本分档、英雄 × Augment × 装备**协同**计算、MMR/ELO 反推与玩家**分层切片**。全部为纯函数模块，可单测、可故障注入。

## 2. 方法论口径（实现 = 唯一真相）

- **Wilson 95% 区间**（z=1.96）：`center=(p+z²/2n)/(1+z²/n)`，`margin=z√(p(1-p)/n+z²/4n²)/(1+z²/n)`，`[lower,upper]=center∓margin`。
- **样本分档**：low `<250`｜medium `250–999`｜high `≥1000`。推荐级：none `<250`｜recommend `≥250`｜strong `≥1000`。
- **排序** `sample_tier_then_wilson_lower_bound_v1`：先按档位（high>medium>low），档内再按 Wilson 下界，再按 pickRate、games。另有对照法 `raw_winrate`（仅用于暴露"小样本霸榜"）。
- **字段语义**：`winRate` = **观测胜率**（wins/games）；`wilson_center` = 向 0.5 收缩后的平滑中心（两者不同，勿混用）。
- **协同 lift**：`lift_vs_hero = 组合胜率 − 该英雄边际胜率`；`lift_vs_global = 组合胜率 − 全局胜率`。**关联非因果**，且需满足最小样本门槛（组合 pair/triple 默认 `≥60`）。
- **MMR/ELO**：`E=1/(1+10^((opp−p)/400))`，`new=p+k(result−E)`，k=32、初始 1500。**分层**按分位：top20=前20%、top40=前40%、all=全量，**保证嵌套** top20 ⊆ top40 ⊆ all（k20=ceil(0.2N)、k40=ceil(0.4N)）。

## 3. 关键发现（重要，勿踩）

🔴 **"小样本高胜率霸榜"的真正压制机制是「样本分档门槛」，不是 Wilson 下界本身。**
当 `p→1` 时 Wilson 下界反而很高（如 17/20 → 下界 0.64 > 55%@800 场的 0.515），所以**单靠 Wilson 下界压不住小样本**。官方排序把档位放在第一关键字后，low 档样本才会稳定排在 high 档之后。→ 复现实验见 `tools/test_m3_unit.py` 的 `t_rank`（"分辨力：高样本高胜率应霸榜"证明档位规则确实在起作用）。

⚠️ 另一处静默分歧：`winRate` 若误写成 Wilson 中心值，会**静默**改变排序与 lift 符号（收缩使 ≈0.8→0.72）。已由单测锁死为观测胜率（本条被 `test_m3_unit.py` 真的抓红过一次）。

## 5. 语料与合规

- **synthetic（默认）**：`data/sample/m3_corpus.synth.jsonl`，由 `gen_fixture.py` 以固定 seed 生成，**仅用于引擎数值校验**。每行强制 `source=synthetic_fixture` / `confidence=fixture` / `is_synthetic=true`，`verify_m3.py` 断言这些标注**不得缺失**，防止合成数据被当真实数据。**绝不与真实数据混合、绝不用于对外结论。**
- **personal**：`data/personal/matches.jsonl`（本人 WeGame/LCU，`secondary`），存在时 `--corpus=personal` 可跑真实切片；当前未采集（待本人凭证）。
- 夹具的 id 口径与真实对局一致：英雄 = champions.csv `key`；Augment = augments.csv `platform_id`；装备 = items.csv `id`。便于未来原样替换为真数据。
