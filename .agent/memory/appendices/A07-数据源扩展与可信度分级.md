# A07 · 数据源扩展调研（隐藏战绩 / 更准局内数据）

> 上级索引：`MEMORY.md` §1（A07）｜触发时机：选数据源、评估可信度、处理隐藏战绩与局内指标之前｜相关：A02 数据源与许可、A04 统计口径

## 0. 结论先行（本轮修正）

- **数据收集从宽**：凡有参考价值的数据都应收集，但每条必须带「**来源 + 可信度 + 时效**」标签。
- 🔴 **完全被隐藏的战绩没有合法外泄渠道**：强制破解/注入/爬取隐藏数据违反腾讯/拳头用户协议，有封号风险 → **本项目不碰**。
- 提升覆盖率与准确度的**正当路径**：**本地 LCU API（自持/授权对局） + 官方·第三方 API 聚合 + 自采样本**，多源**交叉校验**代替"追求单源真相"。

## 1. 数据源分层（按可信度 / 合规性）

| 层级 | 来源 | 覆盖 | 可信度 | 合规 / 风险 |
|---|---|---|---|---|
| **元数据（权威）** | Data Dragon / CommunityDragon | 英雄/装备/Augment 名称·图标·数值 | 高（官方） | 自由使用 |
| 官方 API（全球） | Riot Games API（match-v5 等） | 全球服（**不含国服**） | 高 | 正规；约 20 req/s/账号 |
| 官方 API（国服） | 腾讯开放平台 / WeGame / 掌上英雄联盟 | 国服 | **中**：局内伤害·承伤统计有偏；隐藏战绩取不到 | 需本人授权；**仅次级佐证** |
| **本地客户端接口** | **LCU API**（`127.0.0.1` 本地 WebSocket/HTTPS，需客户端令牌） | 本机账号可见范围 | 中高（较全，含部分隐藏字段） | 本地运行、不上传、不注入内存；相对最稳 |
| 第三方聚合 | OP.GG / U.GG / **BEST.GG** / LeagueofGraphs / Blitz.gg | 全球为主；BEST.GG 国服较好 | 中（Riot API 聚合；隐藏号仅显示 privacy mode 基础数据） | 只读公开数据；守其 ToS |
| 国服第三方 | 绩查查 / SQGG / League Akari 等 | 国服 | 中低 | **灰产注意**：部分靠爬虫/破解，勿依赖、勿复制其代码 |
| 轻量封装 | 微信小程序（中韩排行 / LOL战绩 / 掌上生涯） | 国服 | 低（12–48h 延迟，仅存 3 个月，广告多） | 仅参考 |

## 2. 隐藏战绩的真相（务实结论）

- 玩家开「生涯不公开」后，第三方站按 Riot/腾讯规则只能显示**总胜场 / 简化数据**（privacy mode），详细对局（击杀/出装/符文/伤害）不可见。
- 国服「隐藏战绩」**基本无合法外泄渠道**；WeGame 的"历史缓存"式间接查询**依赖你与该玩家交手过 / 本地缓存**，覆盖有限、不可靠。
- **本项目的可行动作**：① 对**自己 / 已授权**对局用 **LCU API** 取全量；② 群体统计继续借聚合站样本；③ 用**多源交叉校验**代替单源真相。

## 3. 局内指标可信度（重要）

- **伤害统计 / 承伤统计**：WeGame 与掌上英雄联盟的口径**都不保证准确**（结算面板与接口常不一致）→ **仅作参考**，须交叉验证并标注来源。
- 更细的"隐藏数据"（每分钟视野分、技能命中率等）在 LCU / 客户端结算接口里更全，但**同样需校验**。
