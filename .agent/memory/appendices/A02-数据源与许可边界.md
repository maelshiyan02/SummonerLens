# A02 · 数据源与许可边界

> 上级索引：`MEMORY.md` §1（A02）｜触发时机：碰数据源、采集、引用、合规之前｜相关：A03 技术栈、A04 统计

## 1. 三层数据来源

| 层次 | 来源 | 说明 |
|---|---|---|
| **对局统计** | hexdata.com.cn / resg.top | 两家均**自建样本**（百万场量级，如亚索 1,829,755 场），**非** Riot 官方统计 |
| **静态元数据** | Riot Data Dragon（名称/图标）+ CommunityDragon（强化符文，Data Dragon 没有） | 自由使用 |
| **国服个人数据** | 腾讯 WeGame 接口 | 与 Riot 全球 API **两套独立体系**，全球 API 不覆盖中国区 |

## 2. 两家统计站画像

- **hexdata.com.cn**：Vite SPA + 每日一次静态构建（SSG）；Patch 16.19 / 2026-09-27 / `hexdata-2026-09-27-f9b948bc5ff0`；排序 `sample_tier_then_wilson_lower_bound_v1`；分段筛选 娱乐/中高/高分段/全量；自研 `HexScore` / `globalHexScore`。
- **resg.top**：Vite + Vue3 纯前端；数据即 ES module（CDN，`/c/zh_cn/v1/*.js`，**注意 `cdn.resg.top/data/*.json` 是 SPA 兜底不是真数据**）；可离线（Service Worker）；分段 全样本/前40%/前30%/前20%；独有跨版本趋势、装备组合、属性推荐。

## 3. hexdata 为 AI 开放的端点（硬约束）

- `robots.txt` 明确 `Allow: /data/ai-summary.json` 与 `Allow: /api/hexdata/answer-cards`；为 GPTBot/ClaudeBot 开权限。
- `ai-summary.json`（~54KB）含 topHeroes(12)/topAugments(12)/heroAliases(172)/methodology/citationPolicy。
- **使用边界（务必遵守）**：检索式获取 ✅；独立模型训练 ❌；批量转载 ❌；商用 ❌。
- **引用必须附**：「数据来源：Hexdata」+ canonical 链接 + `buildId` + `reportPatch` + `reportDate`。

## 4. 腾讯 WeGame 接口（国服）

| 接口 | 端点 | 说明 |
|---|---|---|
| 战报 | `https://www.wegame.com.cn/api/v1/wegame.pallas.game.LolBattle/GetBattleReport` | 按召唤师查段位/赛季数据 |
| 对局列表 | `https://m.wegame.com.cn/api/trpc/Proxy/Forward/.../GetBattleList` | 按 id+大区查最近对局 |
| 对局详情 | `.../GetBattleDetail` | 单局 KDA/英雄/装备 |
| 昵称查号 | `https://m.wegame.com.cn/api/mobile/lua/proxy/.../query_by_nick` | 昵称→id+大区 |

**关键推论**：
1. hexdata「追溯到腾讯 API」大概率指拉 WeGame/掌盟战报（个人战绩），底层是这群接口。
2. 这些接口**需本人登录授权（cookie/token）**，属个人账户数据。本地工具走「分析自己」路线最稳、合规；**禁止批量拉他人数据**（违反 ToS）。
3. 国服（腾讯）与全球服（Riot API）数据不通。

## 5. 数据策略（采用 C 混合）

| 方案 | 说明 | 评价 |
|---|---|---|
| A. 借 hexdata 公开 JSON | 零采集、质量高、每日更新 | 起步最快，受许可约束（标注、非商用） |
| B. 自采 WeGame API | 完全自主、可分析自己 | 需本人 token；样本量有限，聚合统计不够 |
| **C. 混合（采用）** | 元数据走 Data Dragon+CommunityDragon（自由）；聚合统计先借 A；个人维度（分段/技能组）走 B 自采 | 兼顾速度与合规 |

**国服 vs 港澳台 vs 外服**：国服（WeGame）是绝对主力，优先做；港澳台（Garena TW）样本稀疏需独立管道；外服走 Riot API 但不覆盖中国区，优先级最低。
