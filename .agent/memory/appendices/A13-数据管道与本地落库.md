- 元数据：`meta_champions`(173) · `meta_items`(870) · `meta_items_modes`(870) · `meta_augments`(223) · `meta_skill_archetypes`(173) · `meta_aliases`(173)

## 3. hexdata 合规（硬约束）

- 端点 `https://hexdata.com.cn/data/ai-summary.json`（robots `Allow`，检索式 allowed）。
- **引用必附四字段**：`buildId` + `reportPatch` + `reportDate` + canonical 链接 + 「数据来源：Hexdata」。
- **usage_policy**：检索 ✅｜模型训练 ❌｜批量转载 ❌｜商用 ❌（落 `citation.json` 并在库中断言）。
- 当前快照：`hexdata-2026-09-27-f9b948bc5ff0`（patch 16.19 / date 2026-09-27）；`data/agg/LATEST` 存指针。
- 口径（methodology）：样本分档 low<250 / medium 250–999 / high ≥1000；Wilson 95% 下限 z=1.96；排序 `sample_tier_then_wilson_lower_bound_v1`。

## 4. WeGame 合规（仅本人 · 红线）

- 🔴 **仅采集本人 / 已授权账号**：`fetch_wegame.py` 内置 `assert_self` 强校验，非本人 id 一律 `PermissionError` 拒绝。
- **不碰强制破解隐藏战绩**（注入/爬取他人隐私违反 ToS）。
- 局内**伤害 / 承伤**口径有偏 ⇒ 输出一律 `confidence="secondary"`，仅参考。
- 凭证来源：环境变量 `SUM_LENS_WEGAME_TOKEN` / `SUM_LENS_WEGAME_COOKIE`，或 `data/personal/wegame_credential.json`（**整个 `data/personal/` 被 gitignore 排除**，仅留 README）。
- 端点：A02 记录部分 WeGame 端点为省略写法 ⇒ 须**本地抓包补全**后填入 `credential.endpoints`；脚本**不臆造端点**。
- 无凭证时脚本**退出码 3 并提示**（不发任何网络请求），属**预期 pending**，非失败。
