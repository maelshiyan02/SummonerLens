## 1. 为什么单独立项

海克斯大乱斗（ARAM Mayhem）的**核心维度 = 英雄 × 强化符文（Augment）× 装备**。Augment 是这一模式区别于常规模式的灵魂，也是三元组里最后补齐的一角。副产物：斗魂竞技场（Arena）共用同一套 augment 定义体系。

## 3. 硬规则（务必遵守）

1. **模式代号**：`CHERRY`=斗魂竞技场 · **`KIWI`=海克斯大乱斗** · `KIWI_JADE`=海克斯(Jade 变体)。别再靠目录名猜。
2. **本地化展开**：`NameTra` / `DescriptionTra` 是 key，**转小写**后查 `stringtable["entries"]`。大写查 0 命中。
3. **`kiwi.bin.json` 过滤**：只取 `dict 且含 AugmentNameId` 的项（其余为 `__linked` 等非 augment 项）。
4. **稀有度**：`kSilver`=银 · `kGold`=金 · `kPrismatic`=棱彩 · `kEventChoice`=事件。
5. `arena-zh_cn.json`（cdragon 聚合）**只是竞技场中文库**，海克斯仅 99/223 同名 ⇒ 海克斯数据自行合成，勿直接采用。
