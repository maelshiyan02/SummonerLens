## 1. 身份（对话中统一识别）

- **英文项目名（唯一）**：`SummonerLens`
- **正式中文名（唯一）**：`召唤师数据分析助手`
- **简略称呼（一律识别为本项目，勿误判为其它软件）**：数据分析软件、本项目数据分析助手、本项目、这个工具、我们的工具、SummonerLens。
- **GitHub**：`git@github.com:maelshiyan02/SummonerLens.git`（SSH，public，账号 maelshiyan02）。

## 2. 产品定位与范围

- **品类**：英雄联盟（LOL）数据分析工具。
- **当前阶段**：深度聚焦「海克斯大乱斗」（官方英文名 **ARAM Mayhem**）。
  - 25.21 版本（2025-10）上线的独立模式，在极地大乱斗基础上加强化符文，**不替代原版大乱斗**；后因热度极高改为**常驻模式**。
  - ⚠️ 必须区分近邻：极地大乱斗（ARAM，无强化符文）/ 无限乱斗（ARURF，hexdata 有独立 `/arurf`）/ 斗魂竞技场（Arena，2v2v2… 也用 Augment 但规则不同）。
- **未来方向**：开发成熟后逐步推进**召唤师峡谷**（Summoner's Rift）数据分析。
- **命名约束**：`Summoner` 统合所有模式、`Lens=洞察`，**即使现在只做海克斯也不要改回 Hex 专属名**（如 HexAnvil/HexPrism）。

## 3. 核心分析维度模型

| 维度 | 说明 | 数据可得性 | 备注 |
|---|---|---|---|
| **英雄 Champion** | 173 位（hexdata 当前 patch 覆盖） | 高 | 名称/图标走 Data Dragon |
| **强化符文 Augment** | 每局 4–5 个，3 选 1 | 高 | 名称/图标走 CommunityDragon |
| **装备 Item** | 含海克斯大乱斗新增 3 件 | 高 | Data Dragon + resg 的 `items.js` |
| **玩家分段 Segment** | 无排位分，但有隐藏 MMR | 中（需自建） | 从对局数据反推，见 A04 |
| **地图 Map** | 当前仅嚎哭深渊 1 张 | 低（当前） | 架构预留 `map` 字段，勿过度设计 |
| **英雄技能组 Skillset** | Q/W/E/R + 被动 | 高 | 做英雄原型标注，见 A04 / M1 |
| **跨服务器 Server** | 国服 / 港澳台 / 外服 | 分源 | 国服最值得做（见 A02） |

**高价值组合**：英雄 × 强化符文 × 装备 的胜率协同，叠加**分段**与**英雄技能原型**两个切片维度。

## 4. 与 mangrove 的关系（隔离）

- 同作者（maelshiyan02），但 **SummonerLens 与 mangrove 是完全独立的两个仓库/工作区/记忆体系**。
- **严禁**在本项目工作里误改大工作区内同级目录 `../Mangrove` 的任何文件，反之亦然。
- 记忆范式**参考** mangrove 的 `.agent` 写法，但内容各自独立。
- mangrove 概况（漫画 AI 汉化流水线，Flutter/Windows）：大工作区内同级目录 `../Mangrove`，仅供范式借鉴，不共享代码。
