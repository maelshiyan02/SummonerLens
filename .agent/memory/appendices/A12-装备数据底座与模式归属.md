# A12 · 装备数据底座与模式归属（ARAM Mayhem）

> 上级索引：`MEMORY.md` §1（A12）｜触发时机：做装备分析、模式归属、装备抓取、表结构设计之前｜相关：A08 知识底座、A10 Augment 底座、A09 传输、A04 统计口径

## 1. 核心结论（一句话）

**海克斯大乱斗没有独立装备目录**；它跑在 **Map12 = 嚎哭深渊**，沿用共享装备池。Data Dragon `item.json`（`item.json` 与 CommunityDragon `items.json` 均为 **870 件，id 集合零差异**）**已完整包含所有模式装备**——没有任何装备在标准 `item.json` 之外。

## 2. 模式与地图（决定性口径）

| mapId | 名称 | 说明 |
|---|---|---|
| 11 | Summoner's Rift | 召唤师峡谷 |
| 12 | **Howling Abyss** | **ARAM / 海克斯大乱斗**（含屠夫之桥等皮肤） |
| 22 | TFT | 云顶 |
| 30 | Arena | 斗魂竞技场 |
| 453 | **Classic Rift（mapStringId `JD`=Jade）** | 经典峡谷怀旧模式 |

- 海克斯大乱斗队列 id：**2400 系列**（`kARAM` 组）；模式数据 `game/maps/modespecificdata/kiwi.bin.json` 只含 **Augment / AugmentSets / ModesQuests / 粒子**，均挂 Map12。
- `game-mode-mutators.json`：MapId 12 皮肤含 `MapSkin_HA_Bilgewater`（屠夫之桥）等，佐证 map12=ARAM。
- 端点 `kiwi-hub.json` 为空 ⇒ 无 ARAM 专属装备清单。

## 3. 装备 id 前缀 = 模式副本（实证）

同一件装备在不同模式有**不同 id 的副本**：

| 前缀 | 模式副本 | 例 |
|---|---|---|
| `12xxxx` | **ARAM** | 123430 毁坏仪式、124011 花晓之剑 |
| `66xxxx` | 召唤师峡谷 | 663039 阿塔玛的清算、664011 花晓之剑 |
| `22xxxx` / `44xxxx` | 竞技场 Arena | 223039、224403 |
| `77xxxx` | **Jade（map453）** | 771001 速度之靴…（共 164 件，其中 153 在官方 jade 清单） |
| `99xxxx` | 特殊 | 994403 金铲铲 |
| 4 位/其它 | base | 3039、1111、6032… |

## 4. 硬规则（务必遵守）

1. **`maps` 字段粗粒度、不可单独作模式判据**：反例 `2051` 守护者号角（ARAM）标 `{11,12}`；`3095` 岚切（峡谷）标 `{11,12,453}`；`223084` 心之钢标 `{12,30}`。
2. **按模式清单优先**：官方端点 **`plugins/rcp-be-lol-game-data/global/default/v1/jade-items.json`** 给出 Jade 模式 153 件（全 77 系）。
3. **`id_family` 用六位前缀判读**（§3），不要用 maps 推。
4. **数据质量**：DD 有 **4 件占位名**（`2008`、`226660`、`772139`、`772140`），分析前需剔除或补名。
