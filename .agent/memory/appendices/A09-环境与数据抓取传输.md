# A09 · 环境与数据抓取传输（本机）

> 上级索引：`MEMORY.md` §1（A09）｜触发时机：写抓取/网络脚本、跑外部命令之前｜相关：A03 技术栈、A05 Git、A02 数据源

## 1. 网络与代理（本机实测 2026-10-11）

- 出网走**代理**：环境变量 `HTTP_PROXY=HTTPS_PROXY=http://127.0.0.1:13223`
  （⚠️ 与旧记的 `7890` 不同，**以当前环境变量为准**）。
- **curl 可用且走系统/代理 CA**（`curl` 访问 ddragon → HTTP 200）。
- ⚠️ **Python 标准库 urllib 证书链验证失败**：
  `SSL: CERTIFICATE_VERIFY_FAILED: unable to get local issuer certificate`
  —— 因本机代理 MITM 的 CA 不在 Python 内置 bundle 中。

## 2. 抓取脚本的传输约定（硬规矩）

- 抓外部 JSON **一律 curl 优先**：`subprocess` 调 `curl -sSL --max-time N -H "User-Agent: …" <url>`，`urllib` 作回退。
  已固化在 `python/etl/fetch_datadragon.py`、`python/etl/build_aliases.py`。
- 若日后改用 venv，可 `pip install truststore && import truststore; truststore.inject_into_ssl()`
  让 Python 信任系统证书；**当前不引入第三方依赖**（仅标准库 + curl）。

## 3. 数据源端点（M1 已用）

- **Data Dragon**：`https://ddragon.leagueoflegends.com`
  - `api/versions.json`（版本列表，**当前最新 16.20.1**）
  - `cdn/<ver>/data/zh_CN/champion.json`（英雄列表）
  - `cdn/<ver>/data/zh_CN/champion/<id>.json`（英雄详情，含技能/被动）
  - `cdn/<ver>/data/zh_CN/item.json`（装备）
- **hexdata AI 端点**：`https://hexdata.com.cn/data/ai-summary.json`
  （检索式获取 allowed；引用须附 buildId + reportPatch + reportDate；训练/批量转载/商用 disallowed）。
