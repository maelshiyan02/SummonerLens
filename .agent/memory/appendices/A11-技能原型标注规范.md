# A11 · 技能原型标注规范

> 上级索引：`MEMORY.md` §1（A11）｜触发时机：改/用技能原型标签、做英雄×符文交叉分析之前｜相关：A04 统计口径、A08 知识底座、W02/W04

## 1. 目的

把英雄的**定性定位**量化为可交叉的标签，供「英雄 × 强化符文 × 装备」分析使用（如高 Poke 英雄配哪类 Augment）。**零对局数据依赖**，可先建。

标签集（7 个）：`mobility / cc / sustain / aoe / burst / range / poke`。

## 2. 标签定义（判定以「英雄是否具备该能力」为准，能力存在即计，不要求主导）

| 标签 | 定义 |
|---|---|
| **mobility** | 具备主动位移（冲刺/跳跃/闪现/传送/突进）**或**显著自我机动增益（常态加速） |
| **cc** | 广义控制：硬控（眩晕/击飞/击退/压制/魅惑/嘲讽/恐惧/变形/昏睡/禁锢/束缚/定身/石化）+ 软控（减速/沉默/致盲） |
| **sustain** | 治疗/护盾/吸血/回血（自身或团队回复能力） |
| **aoe** | 具备范围（多目标）伤害或效果 |
| **burst** | 具备高爆发终结能力（处决/斩杀/真实伤害/暴击型连招） |
| **range** | 普攻远程（`attackrange ≥ 300`）——**仅由普攻射程决定** |
| **poke** | 具备远程消耗能力（以远程技能在安全距离持续削血） |

## 3. 判定规则（硬性）

1. **否定语境剔除**：「免疫减速」「无法使用位移技能」**不算**具备该能力。
2. **技能名不计入**：只用技能**描述**匹配，避免"逆流投掷"误报 range。
3. **range 只看普攻射程**；近战若有远程技能，另记 `has_ranged_skill`。
4. 标签可多选；`poke`/`burst` 属**程度性**标签，规则易漏，依赖人工校订。

## 4. 流程（自动底稿 → 人工校订 → 验收）

1. `python python/etl/build_skill_archetypes.py [ver]` → 生成 `auto_tags` + `auto_evidence`（技能级证据）。
2. 逐条复核，写 `data/meta/<ver>/archetype_overrides.json`（`{cid:{tags,status,note}}`）。
3. 重跑脚本合并 → `manual_tags`（无 override 时回退 `auto_tags`）。
4. `python tools/verify_archetypes.py <ver>` 验收；`--self-test` 做故障注入自检。

## 5. 产物与验收

- 文件：`skill_archetypes.csv`（列 `championId/key/name/title/ddragon_tags/ranged/attackrange/hp/auto_tags/auto_evidence/has_ranged_skill/manual_tags/manual_evidence/review_status`）、`archetype_overrides.json`。
