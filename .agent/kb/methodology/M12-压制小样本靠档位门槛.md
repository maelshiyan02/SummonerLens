# M12 · 压制小样本霸榜：靠「样本分档门槛」，不要只靠 Wilson 下界

> 可迁移方法论（与项目无关）。一句话：**Wilson 下界在 p→1 时不压低，单靠它压不住小样本；必须把"样本档位"放在排序第一关键字。**

## 症状

排行榜被"小样本高胜率"占据（如 17 胜 3 负 = 85% 排第一），你加了 Wilson 95% 下界仍压不住——因为那条 17/20 的**下界依然是 0.64**，反而高于 55% @ 800 场的下界 0.515。

## 根因

Wilson 下界是"用区间下沿代表胜率"，**收缩幅度随 p 接近 0 或 1 而减小**（越极端越自信）。所以：

- p≈0.5 时收缩明显（0.5@100 → 0.40）；
- p≈1 时几乎不收缩（1.0@10 → 0.72；17/20 → 0.64）。

即：**Wilson 下界治的是"中间胜率的抖动"，治不了"极端值 + 小样本"**。真正稳定、可解释的护栏是**样本量门槛**（分档）。

## 规矩

1. 排序用**复合键**：`样本档位 → Wilson 下界 → 选择率 → 样本量`（档位当第一关键字）。
2. 档位阈值写死并单测边界（如 `low <250 / medium 250–999 / high ≥1000`），推荐门槛同理（`≥250 可推荐 / ≥1000 强推荐`）。
3. **分档与下界都要**，但职责不同：档位负责"挡在门外"，Wilson 负责"门内排序"。
4. 反向验证必须能证明"档位规则真的在起作用"：构造一个**高样本高胜率**的实体，断言它能霸榜（若档位失效，它会被错误压下去）。

## 反例 / 检查清单

- [ ] 有没有对照实现（`raw_winrate`）来暴露"小样本霸榜"？没有对照就无法证明修复有效。
- [ ] 断言是不是只测了"小样本被压低"？**必须再测一条"高样本高胜率能霸榜"**，否则把所有人都压低也能过。
- [ ] 排序键是否把档位放在第一？只按下界排 = 没修。
- [ ] 阈值边界（249/250/999/1000）是否有单测？—— 边界才是最容易静默错的地方。
- [ ] "胜率"字段是**观测胜率**还是**收缩后中心值**？误用后者会静默改变排序与差值的符号（见 M03）。
