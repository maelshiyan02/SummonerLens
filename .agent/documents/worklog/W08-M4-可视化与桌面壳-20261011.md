## 二、做法（三层 + 单一数据源）

1. **数据束**：`python/bridge/build_viz_bundle.py` 把 hexdata 真实聚合（`data/agg/<buildId>/top_*.csv`）
   与 M3 合成夹具（`data/derived/m3/synthetic/*.csv`）聚合成 `app/web/data/dashboard.json`；
   缺 M3 派生时自动跑 `run_m3.py` 补齐（自举）。真实/夹具**严格分区**、各自标注 `prov.kind`。
2. **离线仪表板**：`app/web`（index.html + style.css + js/core.js + js/app.js），ECharts 5.5.1 **内置**于
   `vendor/`（Apache-2.0，含 LICENSE/NOTICE/sha256）；页面**零 CDN 外链**。
   `core.js` 为纯函数（UMD），浏览器与 node 共用 → 前端逻辑可 headless 单测。
3. **本地服务**：`python/bridge/serve.py` 仅绑 `127.0.0.1`，打印 `SUMMONERLENS_SERVE <url>`；
   提供 `/api/health` 与 `/api/rebuild`（联动数据层重建）。
4. **桌面壳**：`flutter create` 生成 `app/`（windows 平台），依赖 `webview_windows`（WebView2）+ `url_launcher`；
   壳拉起 bridge 并解析 marker 得到装载地址；左侧导航四页 + 顶栏数据源切换/刷新/重建/浏览器打开/日志；
   导航与筛选通过 **URL 查询参数**（`?tab=&dataset=`）驱动同一个仪表板 → 筛选器真正联动数据层。
5. **纪律**：新增 `tools/flutter_task.py`（**禁止裸跑 flutter/dart**）与 `tools/run_headless_task.py`（无头校验总闸）。

## 四、踩坑与修复（重要）

1. **面板 `display:none` 时 init ECharts → 柱子不可见**（坐标轴却在）：容器尺寸 0。
   修：强制回流 → `resize()` → `setOption`，切页后再兜一次。
2. **类目轴 `markLine.xAxis` 传数值被当索引** → 阈值线不画；改用分箱索引。
3. **真实数据 CI 窄到不可见** → 改「浅色观测胜率条 + 实色 Wilson 下界条」双条叠加。
4. **单测断言自洽**（改输入左右一起变）→ 故障注入只红 2 条；改为与独立基准（`rank` 字段 /
   `dataset_index` 行数 / `fixture_meta.strata.n`）比对 + 「只留 X」必须非空 → 注入升到 12 条真变红。
5. 分层阈值最初缺失：数据束在补 `strata` 字段前生成 → 需**重建数据束**（此坑已由 `--self-test` 与
   `/api/rebuild` 覆盖）。
