2. **离线仪表板**：`app/web`（index.html + style.css + js/core.js + js/app.js），ECharts 5.5.1 **内置**于

4. **桌面壳**：`flutter create` 生成 `app/`（windows 平台），依赖 `webview_windows`（WebView2）+ `url_launcher`；
   壳拉起 bridge 并解析 marker 得到装载地址；左侧导航四页 + 顶栏数据源切换/刷新/重建/浏览器打开/日志；
   导航与筛选通过 **URL 查询参数**（`?tab=&dataset=`）驱动同一个仪表板 → 筛选器真正联动数据层。
5. **纪律**：新增 `tools/flutter_task.py`（**禁止裸跑 flutter/dart**）与 `tools/run_headless_task.py`（无头校验总闸）。

## 七、补丁：webview 初始化竞态（同日，用户实测后）

- 用户实测桌面壳：界面与导航正常，但**内容区全黑**，状态栏
  `装载失败：LateInitializationError: Field '_methodChannel@46340896' has not been initialized`。
- **根因**：`ShellPage._boot()` 在 `setState(_baseUrl = url)` 后**同帧**就 `await _wc.loadUrl(...)`；
  而 `DashboardWebview` 要到下一帧才挂载、`controller.initialize()` 才被调用。
  插件的 `_methodChannel` 是 `late` 字段、只在 `initialize()` 里赋值（`src/webview.dart:102 / 175 / 282`）⇒ 竞态崩溃。
- **修复**（`app/lib/widgets/dashboard_webview.dart` + `app/lib/pages/shell_page.dart`）：
  `onInitialized` 就绪回调 + webview 常驻挂载（与起服务并行）+ `_navigate()` 受 `_webviewReady` 门控 + dispose 门控 + `onLoadError`。
- **验证**：`dart format` 语法通过；**构建链未能在本会话执行**（见 §八），待用户本地验证。
