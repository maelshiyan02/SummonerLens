## 三、关键发现（踩坑 / 规则）

1. **模式代号**：`CHERRY`=斗魂竞技场 · **`KIWI`=海克斯大乱斗** · `KIWI_JADE`=海克斯(Jade 变体)。海克斯当前启用池 **223** 条。
2. **本地化 key 规则（核心）**：augment 的 `NameTra`/`DescriptionTra` 是**字符串 key**，展开方式 = **key 转小写**后查 `stringtable["entries"]`。
   - 例：`Kiwi_ARAM_LegDay_Name` → `kiwi_aram_legday_name`；`Cherry_LegDay_Tooltip` → `cherry_legday_tooltip`。
   - 反向验证：原样（大写）查 0/50 命中，小写查 50/50 命中。
3. **`kiwi.bin.json` 结构**：含非 dict 项（`__linked` 等），必须过滤出 `dict 且含 AugmentNameId` 的项 → 恰为 223 条（= 当前池）。
4. **`cherry-augments.json` 100% 覆盖海克斯**（按 `augmentNameId` 223/223），提供英文名/稀有度/图标。
5. `arena-zh_cn.json`（cdragon 聚合）只是**竞技场**中文库，仅 99 条与海克斯同名 → **弃用**，改用 kiwi.bin + stringtable 自合成（100% 覆盖）。
