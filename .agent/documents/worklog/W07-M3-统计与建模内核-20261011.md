## 一、目标

在 M1（知识底座）/ M2（数据管道）之上落地**统计与建模内核**：

- Wilson 95% 下界排序 + 样本分档（<250 / 250–999 / ≥1000）
- 英雄 × Augment × 装备 胜率协同计算
- MMR/ELO 反推 + 玩家分层（前20% / 前40% / 全量）切片
- 验收：小样本高胜率不霸榜；分段切片正确；ELO 公式单测通过（含反向验证）

## 二、做了什么

### 1. 统计内核（`python/stats/`，纯标准库）

- `wilson.py`：Wilson 区间/下界、样本分档、推荐级、**两种排序**（`raw_winrate` 对照 / `sample_tier_then_wilson_lower_bound_v1` 官方）、反霸榜报告。
- `mmr.py`：期望得分、单步更新（k=32）、序列估计、**分位分层**（top20/top40/all，保证嵌套）、皮尔逊相关。

### 2. 建模内核（`python/model/`）

- `synergy.py`：组合枚举（英雄标量 / Augment·装备数组笛卡尔积）→ 组合胜率 + Wilson + **协同 lift**（vs 英雄边际 / vs 全局）。
- `slices.py`：按玩家分层切片聚合。
- `gen_fixture.py`：**确定性合成夹具**（固定 seed，标注 `synthetic_fixture`，仅用于引擎校验）。
- `run_m3.py`：编排 → `data/derived/m3/<corpus>/`（10 张表 + `stats_meta.json`）。

### 3. 夹具设计（关键：植入信号不被稀释）

- 植入英雄（**不进入背景池**）：anchor 1200 局（high 档）/ solid 350 局（medium）/ trap 40 局高胜率（low）。
- 植入组合块：6 组 (英雄, Augment, 装备)，每组 150 局中性底样本 + 100 局植入 effect（+0.20…−0.10），把"协同效应"与"英雄本身强度"分离。
- 玩家潜分 ~N(1500,220)，胜率由 ELO 期望 + 英雄/协同偏移决定 → MMR 可被反推。

## 四、踩坑与修正（都被断言"真的抓红"）

1. **`winRate` 误写成 Wilson 中心值**：收缩使 0.80→0.7165，**静默**改变排序与 lift 符号 → 单测 `(1,10) 胜率 0.8` 抓红 → 改为观测胜率 `wins/games`（`wilson_center` 另存）。
2. **夹具植入被背景样本稀释**：trap 胜率 0.85 被拉到 0.66、协同 lift 趋 0 → 把植入英雄移出背景池 + 加中性底样本。
3. **组合表无支撑**：随机 Augment/装备使组合稀疏 → 引入"植入组合块"，三张组合表各 6 行。
4. **验收脚本布尔列被当字符串**（`"False"` 为真）→ 分层人数误判 80≠16 → `to_num` 识别 True/False。
5. **hero×装备表字段映射写错**（拿 item_id 比 augment）→ 改为按表声明 (行键←清单键) 映射。

## 五、关键发现（已入 A14 §3）

🔴 **压制小样本霸榜靠的是"样本分档门槛"，不是 Wilson 下界本身**：`p→1` 时下界反而高（17/20→0.64 > 55%@800 场的 0.515）。档位作为第一排序键才稳定把 low 档压下去。
