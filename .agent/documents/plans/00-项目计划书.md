## 一、产品与技术定位（不可动摇）

## 三、数据策略（采用 C 混合）

| 数据 | 来源 | 合规要点 |
|---|---|---|
| 静态元数据（英雄/装备/Augment 名称图标） | Data Dragon + CommunityDragon | 自由使用 |
| 聚合统计（胜率/分段/趋势） | hexdata `/data/ai-summary.json` | **检索式✅ / 训练❌ / 批量转载❌ / 商用❌**；引用必带 来源+buildId+reportPatch+reportDate |
| 个人/局内维度（分段/技能组/伤害·承伤） | WeGame / 掌上英雄联盟（**次级佐证**）+ 本地 LCU API | 局内统计有偏、隐藏战绩取不到；**从宽采集但须分级标注可信度并交叉校验**（见 A07） |
| 跨服 | 国服(WeGame) 优先；港澳台/外服 可选项、最低优先级 | 两套独立体系，数据不通 |

**扩展源（见 A07）**：本地 LCU API（自持/授权对局取全量）、OP.GG / U.GG / BEST.GG / LeagueofGraphs（群体样本交叉校验）；**不碰强制破解隐藏战绩**。

**本地落库**：SQLite / DuckDB / Parquet；统计与建模全在本地跑。
